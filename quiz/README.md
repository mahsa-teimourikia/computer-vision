# Knowledge checks

Each completed course has a focused checkpoint embedded in the [Learning Hub](../hub/index.html#curriculum). The available checks cover all nine Beginner courses plus Intermediate 01: foundations, efficient CNNs, vision transformers, self-supervised learning, detection, segmentation, retrieval, tracking/pose, vision foundation models/open-vocabulary vision, and vision-language models. Intermediate 01 adds six questions spanning visual-token interfaces, projection, resampling, grounded generation, evidence ablation, structured outputs, and deployment evidence. A future cumulative assessment can test transfer across the sequence without replacing these lesson-level checks.
