# Knowledge checks

Each completed course has a focused checkpoint embedded in the [Learning Hub](../hub/index.html#curriculum). The available checks cover all nine Beginner courses: foundations, efficient CNNs, vision transformers, self-supervised learning, detection, segmentation, retrieval, tracking/pose, and vision foundation models/open-vocabulary vision. Course 09 closes the track with six synthesis questions spanning reusable interfaces, prompt and vocabulary contracts, dense features, composition, adaptation, and provenance. A future cumulative assessment can test transfer across the complete sequence without replacing these lesson-level checks.
