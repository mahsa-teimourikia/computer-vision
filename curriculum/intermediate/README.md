# Intermediate track

Move from reusable visual perception into multimodal systems that generate, retrieve, compare, and act on visual evidence. The track keeps perception, grounding, reasoning, retrieval, generation, tool use, and authorization as distinct contracts.

## Available

- [01 · Vision-Language Models: From Visual Features to Multimodal Reasoning](01-vision-language-models/README.md) — trace visual tokens through projection, resampling, fusion, and autoregressive generation; test counting, spatial, evidence, hallucination, and systems behavior; and design a governed VLM service.

## Planned progression

2. **Multimodal Reasoning** — decomposition, verification, tool use, and claim-level evidence without relying on hidden chain-of-thought.
3. **Document Intelligence** — layout, OCR, tables, charts, forms, long documents, and provenance-aware extraction.
4. **Multimodal Retrieval / RAG** — chunking, multimodal indexes, evidence assembly, citation evaluation, and access control.
5. **Video-Language Understanding** — temporal sampling, event localization, streaming context, and long-video evaluation.
6. **Visual Agents** — typed tools, browser/GUI/spatial actions, permissions, budgets, stop conditions, and trace evaluation.
