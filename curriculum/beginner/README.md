# Beginner track

Build intuition for how images become numerical inputs, learned representations, and measurable decisions. Start with a compact but complete enterprise scenario, then deepen each architecture family and task in later courses.

After this track, learners should be able to inspect image, representation, localization, segmentation, retrieval, and temporal-state pipelines; implement deterministic baselines; choose capability-specific metrics; recognize leakage and propagation errors; compare specialist and foundation systems; and design a bounded visual decision workflow.
