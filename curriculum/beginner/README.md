# Beginner track

Build intuition for how images become numerical inputs and how simple baselines reveal data, representation, and evaluation problems before deep learning adds complexity.

After this track, learners should be able to inspect an image pipeline, implement deterministic baselines, choose meaningful metrics, recognize leakage and representation errors, and train a bounded first classifier.
