# Advanced 06 diagrams

Each SVG is rendered deterministically from the matching coordinate specification in `specs/` with `scripts/render_course_diagrams.py`. Specifications declare canvas bounds, groups, nodes, ports, connector routes, semantic colors, accessibility text, validation checks, and reproduction source.

The diagrams are designed for both the README and the notebook. They use opaque backgrounds, embedded titles/descriptions, and no browser-side rendering dependency.
