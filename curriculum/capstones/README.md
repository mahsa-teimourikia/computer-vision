# Capstones

Capstones integrate completed prerequisite courses into production-style systems. They are not standalone tutorials and will be built only after their dependency paths are available.

1. Enterprise visual inspection platform
2. Multimodal enterprise knowledge system
3. Video intelligence platform
4. Spatial intelligence system
5. Embodied vision agent

See the [curriculum architecture](../../docs/CURRICULUM_ARCHITECTURE.md#capstones) for scope, deliverables, and prerequisites.
