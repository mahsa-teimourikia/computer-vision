BEGINNER · LESSON 01

Image fundamentals

45–60 MIN · CPU ONLY

OUTCOME

Trace an image from numeric representation to binary prediction, measure the result, and diagnose a real distribution shift.

A vision pipeline is a chain of contracts. Shape, channel meaning, dtype, and numeric range must be explicit before any transformation or model can be trusted.

Read the chapter ↗Open notebook ↗

WATCH FOR

  • Range mismatch
  • Illumination shift
  • Metric blindness
  • Evaluation leakage

PRACTICAL LAB

Build the fixed-threshold baseline, sweep the decision boundary, darken the scene, and measure a bounded recalibration.
